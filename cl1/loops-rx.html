# 몇 번? 어떤 값들?

range(a, b) 는 a부터 시작해서 b 바로 앞까지입니다. b는 포함하지 않습니다. 그래서 5가 아니라 4번입니다.
함정걸음이 +1 일 때, 시작이 끝보다 작으면 횟수는 b - a 입니다. 그렇지 않으면 0번 — 아래 표의 8·9번이 그것입니다. range(n) 은 0부터 n-1까지 n번. 헷갈리면 작은 수로 손으로 써 보세요.

유형 3

반복의 범위

★ 필수 — 함정 ② 범위
이렇게 나옵니다 — 한 칸 차이로 답이 달라집니다
# A
total = 0
for i in range(1,6):
    total += i
print(total)

# B
for i in range(1,6):
    total = 0
    total += i
print(total)
A: 15   B: 5
B는 total = 0 이 반복 안에 있습니다. 매번 0으로 초기화되니 마지막 값 5만 남습니다.

초기화는 반복 밖, 누적은 반복 안. 이 한 줄이 반복문의 절반입니다.
함정들여쓰기 한 칸이 반복 안인지 밖인지를 정합니다. 코드 왼쪽에 세로줄을 그어 어디까지가 반복인지 표시하고 읽으세요.

while과 종료 조건

★ 필수 — 함정 ④ 종료
이렇게 나옵니다
n = 1
while n <= 5:
    print(n, end=' ')
    n += 1
답: 1 2 3 4 5
while 은 조건이 참인 동안 반복합니다. 조건이 거짓이 되거나 break 를 만나야 끝납니다. 그래서 셋을 봅니다 — ① 시작값 n = 1 · ② 반복할 조건 n <= 5 · ③ 그 조건을 언젠가 거짓으로 만들 줄 n += 1.
③이 빠지면 영원히 돕니다.

중첩 반복

★ 필수 — 함정 넷이 한꺼번에
이렇게 나옵니다 — 안쪽이 몇 번 도는지가 관건입니다
c = 0
for i in range(3):
    for j in range(2):
        c += 1
print(c)
답: 6
바깥이 한 바퀴 도는 동안 안쪽이 처음부터 끝까지 다 돕니다. 바깥 3번 × 안쪽 2번 = 6번.
안쪽 횟수가 바깥 i 에 따라 달라지면 곱셈이 아니라 더하기입니다. range(i+1) 이면 1+2+3 = 6.
함정break 는 자기가 들어 있는 반복 하나만 빠져나옵니다. 안쪽에서 break 해도 바깥은 계속 돕니다. 그리고 초기화를 어느 반복 안에 두었는지 반드시 확인하세요 — 유형 3에서 본 그 한 줄이 여기서 다시 나옵니다.
