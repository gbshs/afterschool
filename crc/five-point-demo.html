Five-Point Scan — 시범

글자

한 줄씩은 다 아는데

여러분은 for if += % 를 다 배웠습니다. 아래 코드에 모르는 문법은 없습니다. 한 줄씩 짚으면 전부 설명할 수 있죠. 그런데도 “이 코드가 무슨 일을 하냐” 고 물으면 막힙니다.

모르는 문법이 하나라도 있나요?

c = 0 best = lst[0] for x in lst: if x > best: best = x if x % 2 == 0: c += 1 print(best, c)

없습니다. 여덟 줄 전부 배운 것뿐입니다. lst[0] 도, % 도, += 도요.

이 코드가 무엇을 하는 코드인지 맞춰 보세요.

  • 1lst 에서 가장 큰 값을 찾는다
  • 2lst 의 짝수 개수를 센다
  • 3가장 큰 값을 찾으면서 동시에 짝수 개수를 센다
  • 4lst 에서 가장 큰 짝수를 찾는다
하나를 눌러 보세요 맞히는 게 목적이 아닙니다. 왜 헷갈리는지를 보려는 겁니다.
낱말은 하나도 안 어려웠습니다. 막힌 건 구조입니다 — 반복 하나 안에 if 가 둘이고, 그 둘이 서로 아무 상관이 없다는 것. 하나가 눈에 들어오면 나머지 하나가 가려집니다.
코드 읽기가 어려운 건 단어를 몰라서가 아니라 줄이 겹치고, 순서가 위에서 아래가 아니고, 덩어리가 눈에 안 띄기 때문입니다.
그래서 낱말이 아니라 전체 모양부터 봅니다.

받고 · 만들고 · 내놓고

앞 화면에서 막힌 이유를 한 마디로 하면 — 반복 안에서 변수 둘(best 와 c)이 따로 자라고 있었기 때문입니다. 하나를 따라가면 나머지가 안 보이죠. 그러니 한 줄씩 읽지 말고 데이터가 어디로 들어와서 무엇을 거쳐 어디로 나가는지부터 봅니다. 그 길목이 다섯입니다.

다섯 다 눈으로 짚히는 것입니다. 뜻을 몰라도 세어집니다. IN → VAR → OUT 이 데이터가 지나가는 길이고, LOOP · DEPTH 가 그 길을 몇 번, 얼마나 깊이 지나는가입니다.

가운데 VAR 이 알맹이입니다. 변수는 무엇으로 시작해서 무엇이 되는지가 정해져 있습니다 — 0 으로 시작해 값이 쌓이면 합계, 1 씩 쌓이면 개수, 빈 리스트로 시작해 골라 담기면 걸러내기. 변수 하나의 일생이 곧 그 코드가 하는 일이고, 변수가 둘이면 하는 일도 둘입니다 — 앞 화면에서 막힌 게 바로 그것이었죠.

코드에 나오는 「이름」은 세 가지입니다 — 섞어 쓰면 안 됩니다
무엇예누가 지었나시험지에서는
파이썬이 정한 이름 popleft append len range 파이썬그대로 나온다 — 믿어도 된다
함수 이름 bfs is_safe validate 코드를 쓴 사람바뀐다 — f
변수 이름 came_from state total 코드를 쓴 사람바뀐다 — d s

아래 두 줄은 쓴 사람이 지은 이름이라 시험지에서 바뀝니다 — 그러니 이름에서 답을 얻으려 하지 않습니다. 이름은 바뀌어도 변수와 변수의 연결은 안 바뀝니다. 우리가 VAR 을 보는 이유가 이것입니다. 대신 첫째 줄(popleft append len)은 파이썬이 정한 이름이라 시험에서도 그대로 나옵니다. 이건 이름이 아니라 동작을 알려 주니 단서로 써도 됩니다.

이름이 아니라 연결을 봅니다. 이름은 쓴 사람 마음이지만, 어느 변수에서 어느 변수로 값이 옮겨 가는지는 코드가 바꿀 수 없습니다.
다음 화면은 시험지처럼 이름이 지워진 코드입니다 — f(a, b, c) 뿐이라 이름에서 얻을 게 하나도 없습니다. 그래도 다섯 곳이 다 읽히는지 직접 해 봅니다.

이름이 하나도 없는 코드로

시험지에 나오는 그대로입니다 — f(a, b, c), 변수는 d q s t. 이름에서 얻을 것이 하나도 없습니다. deque 처럼 처음 보는 것도 하나 섞여 있지만 그것도 문제가 아닙니다. 줄이 겹치고 return 이 여러 군데라 어디부터 볼지가 문제죠.
