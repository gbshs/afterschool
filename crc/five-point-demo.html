한 줄씩은 다 아는데

여러분은 for if += % 를 다 배웠습니다. 아래 코드에 모르는 문법은 없습니다. 한 줄씩 짚으면 전부 설명할 수 있죠. 그런데도 “이 코드가 무슨 일을 하냐” 고 물으면 막힙니다.

모르는 문법이 하나라도 있나요?

c = 0 best = lst[0] for x in lst: if x > best: best = x if x % 2 == 0: c += 1 print(best, c)

없습니다. 여덟 줄 전부 배운 것뿐입니다. lst[0] 도, % 도, += 도요.

그럼 이 코드는 무엇을 하나요? 하나 골라 보세요. 먼저 고르고 누르는 게 좋습니다.

  • 1lst 에서 가장 큰 값을 찾는다
  • 2lst 의 짝수 개수를 센다
  • 3가장 큰 값을 찾으면서 동시에 짝수 개수를 센다
  • 4lst 에서 가장 큰 짝수를 찾는다
하나를 눌러 보세요 맞히는 게 목적이 아닙니다. 왜 헷갈리는지를 보려는 겁니다.
낱말은 하나도 안 어려웠습니다. 막힌 건 구조입니다 — 반복 하나 안에 if 가 둘이고, 그 둘이 서로 아무 상관이 없다는 것. 하나가 눈에 들어오면 나머지 하나가 가려집니다.
코드 읽기가 어려운 건 단어를 몰라서가 아니라 줄이 겹치고, 순서가 위에서 아래가 아니고, 덩어리가 눈에 안 띄기 때문입니다.
그래서 낱말이 아니라 지형부터 봅니다.

코드에서 짚을 곳은 다섯입니다

방금 막힌 건 줄이 겹쳐 있어서였습니다. 그러니 한 줄씩 읽어 내려가면 안 됩니다. 먼저 코드 전체의 모양부터 봅니다. 이 다섯 곳이 그 모양입니다 — 다섯 다 「세면 되는 것」이라 뜻을 몰라도 짚힙니다.

다섯 다 눈으로 짚히는 것입니다. 뜻을 몰라도 짚을 수 있습니다. 그래서 모르는 코드에서도 됩니다.

NAME · IN · OUT 은 무슨 일을 하는가를 말해 주고, LOOP · DEPTH 는 얼마나 무거운 일인가를 말해 줍니다. 앞의 셋으로 문장을 만들고, 뒤의 둘로 이 코드를 얼마나 조심해서 읽어야 할지를 정합니다.

코드에 나오는 「이름」은 세 가지입니다 — 섞어 쓰면 안 됩니다
무엇예누가 지었나시험지에서는
파이썬이 정한 이름 popleft append len range 파이썬그대로 나온다 — 믿어도 된다
함수 이름  NAME bfs is_safe validate 코드를 쓴 사람바뀐다 — f
변수 이름 came_from state total 코드를 쓴 사람바뀐다 — d s

앞 화면에서 popleft 를 단서로 쓴 건 첫째 줄이라 괜찮았습니다. 아래 NAME 은 둘째 줄 — 시험에서는 없다고 보고 시작합니다.

다섯 중 NAME 하나만 이름에 기댑니다. 그런데 시험지에는 이름이 없습니다 — f a b c 로 나오죠. 그러니 NAME 은 주면 받고 안 주면 버리는 자리로 두고, 나머지 넷을 진짜 무기로 삼습니다. 다음 화면에서 직접 확인합니다.

줄이 훨씬 많고 겹도 깊습니다. deque 처럼 처음 보는 게 하나 섞여 있지만 그건 문제가 아닙니다. 반복이 겹치고 return 이 여러 군데라 어디부터 볼지가 문제죠. 다섯 곳으로 지형부터 잡습니다.
